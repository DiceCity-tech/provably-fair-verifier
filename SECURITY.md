# Security

If you find a security problem in this verifier, or a way the method could
let anyone know or change a result before it is played, please tell us
privately by email to support@dicecity.com, with "Security" in the subject line.

Please do not open a public issue for it. Include what you found and how to
see it. We will reply, and we will say in the changelog when it is fixed.

Questions about an account, a deposit, a withdrawal or a bet are not
security reports; please contact support on dicecity.com.
